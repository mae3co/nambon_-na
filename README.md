# 남이 본 나

내가 답한 나와 친구들이 본 나를 비교하는 성향 테스트.

1. 질문 12개에 내가 먼저 답하고 링크를 친구들한테 보낸다.
2. 친구는 별명을 정하고, "이 친구라면 이렇게 할 것 같다"로 답한다.
3. 다 답하면 친구에게 진짜 4글자가 공개되고, 다른 친구들 평가도 볼 수 있다.

결과 화면
- 한 줄 별명: 진짜 나 vs 친구들 눈에 비친 나
- 가장 큰 반전: 나는 A라고 했는데 친구 대부분은 B라고 한 장면
- 들킨 나, 숨은 나: 조하리의 창(다 아는 나 / 남만 아는 나 / 나만 아는 나)
- 친구끼리도 갈린 장면
- 누가 나를 제일 잘 알까: 비슷하게 본 친구일수록 가운데 가까이

## 구성
- `index.html` 화면 전부 (HTML, CSS, JS 한 파일). GitHub Pages로 배포.
- `supabase/schema.sql` 테이블 2개(mirrors, responses)와 RLS 정책.
- DB: Supabase. 로그인 없음, 결과 공개. 브라우저에는 publishable 키만 들어간다 (secret 키는 절대 넣지 않음).

## 로컬에서 보기
`index.html`을 브라우저로 열거나 `npx serve .`
